# PANTONE® Color Books

16 color libraries for Adobe Illustrator 2024 and newer.

```
graphics/                  11 × .acb   Solid, Color Bridge, CMYK, Extended Gamut,
                                       Metallics, Pastels & Neons, SkinTone™
fashion-home-interiors/     4 × .ase   Cotton TCX, Paper TPG, Polyester TSX, Metallic Shimmers TPM
                            1 × .acb   Nylon Brights TN
```

## Install `.acb` libraries (Color Books menu)

1. Quit Illustrator.
2. Copy the `.acb` files into Illustrator's **Color Books** folder
   (replace `2024` with your version and `en_US` with your language folder):

   - **Windows:** `C:\Program Files\Adobe\Adobe Illustrator 2024\Presets\en_US\Swatches\Color Books\`
   - **macOS:** `/Applications/Adobe Illustrator 2024/Presets.localized/en_US/Swatches/Color Books/`

   Allow the administrator prompt if one appears and overwrite existing files.
3. Start Illustrator → **Window › Swatches** → panel menu **☰ › Open Swatch Library › Color Books**.

## Load `.ase` libraries (any Adobe app)

**Window › Swatches** → panel menu **☰ › Open Swatch Library › Other Library…** → choose the `.ase` file.
